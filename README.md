# [拼图与星空](https://hoo.be/merids)

林夏的周末午后，总消磨在街角那家叫“拾光”的旧书咖啡馆里。她有个古怪的癖好：沉迷于店里那盒永远也拼不完的、没有参考图的旧拼图。

那天，她照常坐到靠窗的老位置，却发现拼图板上多了一小块已完成的区域——是夜空中最亮的几颗星，拼得工工整整。旁边，坐着一个眉眼干净的男生，正对着散乱的碎片蹙眉。

“你好，这是我一直在拼的部分。”林夏指了指那块星空，语气温和却带着一丝领地宣告的意味。

男生抬起头，眼里闪过一丝歉意，随即化为笑意：“抱歉，我看这里空着，就忍不住动了手。这幅拼图太难了，没有图样，像在盲人摸象。我叫陈序。”

“林夏。”她在他对面坐下，“没有图样才好，每一次都是未知的相遇。”

就这样，一场无声的“领土谈判”变成了默契的合作。他们约定，每周六下午，各自拼凑，最后再将成果融合。林夏擅长捕捉色彩渐变，能迅速找出属于晚霞或森林的碎片；陈序则逻辑缜密，善于从形状怪异的边角料里构建轮廓。

他们拼图时话不多，偶尔交流也是只言片语。
“这块蓝，应该是湖水的倒影。”
“那个锯齿状的白边，我猜是远处雪山的风。”

在寻找碎片与严丝合扣的细微声响中，时光静静流淌。他们开始分享拼图之外的生活：林夏是绘本画家，笔下的世界充满梦幻色彩；陈序是程序员，代码世界里追求绝对的秩序。两个截然不同的灵魂，却在这方小小的拼图板上找到了奇妙的共振。

三个月后，拼图完成了大半，显现出壮丽的银河与深邃的宇宙。只剩最后一片天空，怎么都找不到。他们翻遍了所有角落，甚至惊动了店主，那片关键的碎片就像蒸发了一样。

林夏有些沮丧，觉得这份共同的作品注定留有遗憾。陈序却看着她的眼睛，轻声说：“也许，它是在告诉我们，完美不一定是圆满。”

下一个周六，陈序递给林夏一个细长的盒子。她打开一看，是一幅小巧的拼图项链。吊坠里，正是那缺失的一片天空形状的碎片，被精心镶嵌其中。

“我找到了它，卡在沙发缝里。”陈序有些不好意思地笑了，“但我不想把它拼回去了。林夏，我们的故事就像这幅拼图，从陌生的碎片开始，一点点摸索，终于拼出了彼此的模样。这最后一片，我想由你保管。你，愿意让我的未来，拼进你的版图吗？”

林夏摸着颈间温凉的碎片，看着眼前人比星河还亮的眼眸，终于明白，最美的爱情，并非毫无缺憾的完美，而是两个独立的个体，像失散多年的拼图片段，在茫茫人海中，终于找到了能严丝合缝嵌入彼此生命的那一块。而那故意的“缺失”，成了最独一无二的圆满。
